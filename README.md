# MIXED Pro Updates

Public update feed for MIXED Pro. This repository contains manifests and
release notes only; application source code is not published here.

- Stable feed: `https://updates.djnanohz.com/stable/update.json`
- Beta feed: `https://updates.djnanohz.com/beta/update.json`

Never publish an internal-candidate DMG. Upload only Developer ID-signed,
notarized, stapled and audited release DMGs. Upload a versioned DMG first, then
generate its manifest and publish the manifest last.
